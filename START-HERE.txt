EASIEST METHOD
--------------
1. Open terminal inside this folder.
2. Run:

   npm install
   npm run setup:email

3. Paste the Gmail App Password when asked.
4. Test email:

   npm run check:email

5. Start project:

   node server.js

6. Open:

   http://127.0.0.1:3000

7. Login:

   admin / Admin@123

The admin OTP should be sent to hassanbadha33@gmail.com.
Forgot Password reset codes also use the same email setup.

MANUAL METHOD
-------------
Open .env and fill only these two lines:

OTP_SECRET=PASTE_GENERATED_64_CHARACTER_SECRET_HERE
SMTP_PASS=PASTE_GMAIL_APP_PASSWORD_HERE

Generate OTP_SECRET with:

node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
